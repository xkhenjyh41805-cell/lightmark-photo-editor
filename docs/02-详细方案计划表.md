## 总览

| 项目 | 内容 |
|------|------|
| 软件名 | 光印 LightMark（暂定，可改） |
| 目标用户 | 会拍照、不会修图的摄影爱好者（先满足你自己） |
| 核心理念 | AI 给建议，人来调。系统化流程 + AI 教学，不替你做决定 |
| 技术栈 | Electron + React + TypeScript + Tailwind + Canvas/WebGL |
| 平台 | 先 Windows 桌面端，后续可转网页端 |

## 横切关注点

| 关注点 | 做法 |
|--------|------|
| 性能 | 预览用低分辨率代理图，导出才用全分辨率 |
| 画质 | 非破坏性编辑，原图不动，只存参数 |
| 可维护 | 图像算法与 UI 分离，advisor 模块独立 |
| 文档 | 每阶段产出说明文档放 docs/ |
| 版本管理 | git，每阶段完成打 tag |
