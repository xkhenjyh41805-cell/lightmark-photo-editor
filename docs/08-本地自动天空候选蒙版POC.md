# 本地自动天空候选蒙版 POC

> 日期：2026-10-14  
> 状态：**已实现 Agent 自动天空选区闭环，待真实模型与真实照片复验**  
> 范围：非生成式、单张、仅天空；普通用户由 Agent 自动调度，手动蒙版保留为检查和专业修正入口。

## 1. 要验证的问题

能否在 LightMark 桌面端把“自动区域选择”做成可靠、可撤销、可校正的传统修图工具，而不是让多模态模型直接输出坐标、笔刷或像素蒙版？

本轮选择**天空**作为技术 POC：它可用语义分割模型的固定类别验证整个链路。产品优先级仍保持“人物 → 宠物 → 背景 → 天空”；本 POC 不代表天空优先于人物，只是先验证最小的本地分割管线。

## 2. 用户流程

### 默认：对话式自动修图

1. 用户直接输入：**“压暗天空一点，保留云层细节。”**
2. 应用优先复用当前照片已有的“天空”语义蒙版；没有时，先在本机下载／缓存模型并生成内存中的临时天空选区。这个阶段可取消，照片不上传、不改图。
3. 候选成功后，应用才将缩小预览、用户指令、当前参数和仅含 `id`／名称／类型的天空描述发送给用户授权的多模态模型。
4. 模型只能对这张精确天空 ID 返回 `adjust_mask`。若模型给出全局／HSL 替代、错误 ID、无局部参数或计划校验失败，应用拒绝计划，临时蒙版不会保存。
5. 通过后，“自动创建天空蒙版 + 局部传统参数”作为**一条原子事务**写入照片。结果卡显示执行原因、参数、**查看／修正范围**和撤销按钮。
6. 撤销会同时移除这张自动天空蒙版和局部参数；恢复会一并恢复。用户点击“查看／修正范围”可转到局部面板检查红色覆盖与笔刷修正。

### 手动：专业检查与兜底

1. 在 **调整 → 局部调整** 点击“生成天空候选蒙版”。
2. 完成后创建一个**禁用、待确认**的“天空（候选）”栅格蒙版；按住 `Alt` 查看红色覆盖范围，可补画／擦除与调整软度。
3. 用户点击“接受候选并启用”后，它变为“天空”蒙版并可被 Agent 复用；也可拒绝并删除。

> 手动候选未采纳前，不影响照片、不参与导出，也不会发送给 Agent。自动路径的临时蒙版则仅在完整局部计划通过验证后才写入照片。

## 3. 本地与隐私边界

- 使用 `@huggingface/transformers` 在 Electron **渲染进程 Web Worker** 中执行语义分割；默认 CPU/WASM `q8` 路径，不要求 Python、CUDA 或额外本地服务。
- 首次模型下载需要网络，来源为公开模型托管；后续由本地缓存复用。
- 用于分割的照片像素仅在当前设备的 Worker 内存中处理；**不会发送给 BYOM 模型、OpenAI 兼容中转站或新的云端分割 API**。
- 为限制 sidecar 体积，候选蒙版最多保存为 512px 边长的单通道权重图；预览和全分辨率导出按归一化坐标平滑缩放，并叠加用户笔刷修正。
- 原图不改。手动候选创建、采纳、拒绝和手动修正沿用照片历史与 sidecar 持久化；自动路径仅在计划安全校验后持久化，并把蒙版与参数合并成同一事务。

## 4. 当前模型与验证

- 模型：`Xenova/segformer-b0-finetuned-ade-512-512`（ADE20K 语义分割，ONNX／Transformers.js）。
- 在本项目安装的 `@huggingface/transformers` 4.3.1 中，以内存构造的蓝天／地面合成图完成模型下载、加载和推理，输出包含 `sky` 单通道 mask。
- 该模型在当前运行时应按模型卡示例使用 `await segmenter(image)`；显式传入 `subtask: 'semantic'` 会触发该版本的后处理不兼容，因此实现刻意不传该参数。升级运行时后必须复测。
- 代码层回归覆盖：栅格蒙版缩放、绘制／擦除修正、损坏候选数据隔离、局部参数只影响候选区域、待确认候选不得被 `adjust_mask` 引用。

## 5. 已知限制与后续

1. **只识别天空。** 并不表示天空蒙版必然正确；逆光、玻璃反射、雾、建筑边缘、树叶遮挡等仍需人工检查和笔刷修正。
2. 当前分割默认 CPU/WASM，首轮下载与首次推理可能慢；需要在真实 Windows 设备上记录模型下载量、首轮和缓存后耗时、内存峰值及取消体验。
3. 人物／宠物的高质量前景范围需要实例分割或可提示分割；背景通常需要主体扣除或全景语义策略。不能简单把天空模型标签换名复用。
4. Agent 不直接画蒙版；已实现的天空路径是“Agent 理解目标 → 本地分割工具生成候选 → 应用端验证 → `adjust_mask`”。人员／宠物 POC 仍需评估多目标、毛发、遮挡与歧义选择，并默认提供人工检查／修正入口。
5. 发布／商用前需独立核查模型、上游权重及运行时依赖许可证。

## 6. 建议真实照片验收

1. 选一张天空清晰、有建筑或树叶边缘的真实照片。
2. 直接输入“压暗天空、保留云层细节”；记录首次下载／推理时间，检查取消是否不创建蒙版、不上传照片。
3. 检查结果卡明确写出自动天空选区，且只显示“天空 · 高光／曝光”等局部参数；若模型未使用自动天空 ID，则应不保存蒙版、不改图。
4. 点击“查看／修正范围”，按 `Alt` 对照红色范围；用笔刷补画天空、擦掉建筑／主体泄漏。
5. 撤销／恢复自动事务，确认天空蒙版、局部参数和 sidecar 一并回退／恢复，全局参数不受影响。
6. 再走手动候选流程，确认用户仍可以自行检查、修正、采纳或删除候选。
