# 光印 LightMark

光印是面向摄影爱好者和非专业用户的 AI 辅助修图桌面 Demo。产品理念是“AI 给建议，人来调整”：软件通过清晰的修图流程和即时提示降低学习门槛，但保留用户对最终效果的控制。

## 当前功能

- Electron + React + TypeScript + Tailwind 桌面应用
- 图片导入、图库管理和缩略图生成
- 曝光、对比度、影调、白平衡、色彩、锐化和降噪
- 实时预览、直方图、前后对比和参数重置
- 新手模式与专业模式
- 规则建议：根据直方图和调整参数提示高光溢出、死黑、偏色等问题
- 渐变、径向和笔刷局部调整
- HSL 八色分区调色
- 修图预设、历史记录、撤销/重做、裁剪和旋转
- 高质量单张导出、批量导出和导出预设
- 调整参数以 sidecar 文件持久化，原图不被修改

## 运行环境

- Node.js
- npm
- Windows（当前主要目标平台）

安装依赖并启动开发环境：

```bash
npm install
npm run dev
```

构建前端资源：

```bash
npm run build
```

运行构建后的桌面应用：

```bash
npm start
```

## 项目状态

当前版本已完成基础修图、局部调整、HSL、预设、历史记录、几何调整和导出功能。现有建议功能主要使用本地规则引擎；真正的视觉大模型接入尚未完成，项目仍属于个人 Demo。
